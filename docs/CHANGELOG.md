# 変更履歴

## 1.1.0 — 分離構成とGitHub Pages

前版1.0.1のスマホ向け修正を基に、実際に配信するファイルを分離しました。

- `index.html` をHTML構造だけにし、CSS・JavaScript・faviconを別ファイル化。
- `defer` を使用して既存のJavaScript依存順を保持。アプリの描画・生成アルゴリズムは維持。
- 分離されたJavaScriptが読み込めない場合のエラー検知を起動監視に追加。
- 静的案内にも、HTML単体ではなくフォルダ全体が必要なことを追記。
- ローカルサーバーをCSS・JS・アイコンの配信に対応させ、`--base=/SILICON-DRIFT/` を追加。
- 公開用ファイルを結合せずコピーする `package:pages` と、mainへのpushで発火するPagesワークフローを追加。
- サブディレクトリの参照・MIME型・配布物・デプロイ設定の自動テストを追加。
- Git・エディター設定、導入手順、検証記録を追加。

この作業では、ユーザーのGitHubリポジトリへのコミット・push・設定変更・デプロイは行っていません。
